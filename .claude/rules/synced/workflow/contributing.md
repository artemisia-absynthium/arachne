# Contributing Patterns Upstream

When you identify a coding pattern, constraint, or convention that should apply across all projects — not just the current one — invoke the `lift-to-shared-rules` skill to propose it upstream.

Treat it as an explicit checkpoint rather than a standing intention: when wrapping up a task, state in one line whether the session surfaced a rule that should apply across projects. The lift itself is a proposal — full text shown, nothing written upstream or pushed without an explicit go. The target repository is public; proactive publication was never appropriate there.
