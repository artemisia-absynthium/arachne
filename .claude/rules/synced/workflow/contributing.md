# Contributing Patterns Upstream

When you identify a coding pattern, constraint, or convention that should apply across all projects — not just the current one — invoke the `lift-to-shared-rules` skill to propose it upstream.

Do this proactively. Do not wait for the user to ask. Because ambient "be proactive" instructions fire unreliably under task focus, treat it as an explicit checkpoint rather than a standing intention: when wrapping up a task, ask "did this session surface a rule that should apply across projects?" — and if so, lift it before considering the task done.
