# UIKit Asset Loading

## UIImage — use ImageResource, not strings

`UIImage(resource:)` (iOS 17+) accepts the type-safe `ImageResource` generated by Xcode for every
image in an asset catalog. It is non-optional — no `guard let` or `!` needed, and no silent failure
if the asset name is mistyped or later renamed.

```swift
// ✅
UIImage(resource: .myIcon)

// ❌ — returns an Optional; silently nil if the name is wrong
UIImage(named: "myIcon")
```

When targeting iOS 16 or earlier, keep the `UIImage(named:)` call but add a `// TODO: upgrade to UIImage(resource:) when minimum deployment raises to iOS 17` comment so it's easy to find and upgrade.

For SwiftUI usage of `ImageResource`, see `swift/assets.md`.
